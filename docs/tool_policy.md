# Política de herramientas y datos

## Principio

La coordinación del máster decide qué herramientas puede utilizar el grupo. Este
curso no presupone que una cuenta gratuita, una licencia institucional o una
función concreta permanezcan disponibles.

## Semáforo de datos

| Categoría | Ejemplo | Acción |
|---|---|---|
| Verde | Enunciado público, datos sintéticos del curso | Puede utilizarse |
| Ámbar | Borrador propio no publicado, dato seudonimizado | Consultar al docente |
| Rojo | Datos personales, secretos, código de empresa, resultados bajo NDA | No cargar |

## Reglas

1. Use solamente cuentas y servicios autorizados.
2. No incluya credenciales, claves API o tokens en prompts, notebooks o commits.
3. Compruebe las condiciones de uso antes de cargar documentos.
4. Declare la herramienta, la fecha y el uso realizado.
5. Mantenga una alternativa sin IA cuando la tarea pueda afectar seguridad,
   calificación o confidencialidad.
6. La persona que entrega el trabajo responde por su contenido.

## APIs opcionales

El curso base no necesita una API generativa. Si una extensión la utiliza, cada
persona debe almacenar su propia clave en el gestor de secretos del entorno. El
repositorio nunca debe contener claves.

## Alcance normativo

Este documento es una propuesta docente y no sustituye la normativa de la
Universidad de Oviedo o del consorcio EU4M. La coordinación debe resolver cualquier
conflicto con las reglas institucionales vigentes.
