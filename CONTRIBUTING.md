# Contribuir

1. Cree una rama corta desde `main`.
2. Mantenga separadas las respuestas de estudiante y de instructor.
3. No añada datos personales, credenciales ni material sujeto a restricciones.
4. Ejecute `python scripts/run_all.py` antes de abrir un pull request. Si cambió una
   diapositiva, ejecute también `python scripts/build_agenda.py`.
5. No edite a mano `notebooks/*.ipynb`: cambie `scripts/build_notebooks.py` y regenere.
   Los CSV se escriben siempre con LF (`.gitattributes` lo fija).
6. Describa qué afirmación, actividad o prueba cambia y por qué.

Las correcciones de contenido deben incluir una fuente o evidencia reproducible.
