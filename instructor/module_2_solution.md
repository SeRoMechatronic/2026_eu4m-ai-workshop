## Relación con la pregunta

Isermann aporta el marco más directo para construir residuos y razonar con un
modelo. Lei y colaboradores ofrecen contexto para métodos basados en datos y sus

## Síntesis aceptable

La literatura de diagnóstico distingue entre evidencia basada en un modelo y
evidencia aprendida de datos. Isermann describe el uso de residuos para comparar
el comportamiento observado con el esperado. Lei y colaboradores revisan métodos
de diagnóstico basados en aprendizaje automático, cuyo rendimiento depende de
datos y condiciones de evaluación. Estas fuentes apoyan la necesidad de combinar
señales y validar el método, pero no establecen un umbral universal para este
actuador sintético. Para separar pérdida de eficacia y sesgo del sensor necesitaríamos
una predicción independiente o una medición redundante.
